Overview / SDK Usage¶

This page mirrors docs/README.md, but is named OVERVIEW.md so it can be included in the MkDocs site without the README.md vs index.md URL conflict.

Nicrypt-Stego¶

Nicrypt-Stego provides cryptographic provenance for text in the AI era by embedding encrypted metadata inside natural language. It is designed for enterprise workflows where origin, compliance, and auditability matter. This approach is feasible today, best suited to server or desktop deployments, and pairs well with on-prem LLMs to preserve privacy and control.

How to use the SDK¶

Install dependencies

python -m venv .venv
. .venv/bin/activate
make setup

Note: this repo is a monorepo. make setup installs: - SDK: pyproject.toml (root) - Client SDK: packages/client/pyproject.toml - API: apps/api/pyproject.toml

Optional (Linux-only, Postfix/Sendmail milter)

This PoC uses pymilter (see poc/postfix_milter.py). Install:

pip install -r requirements-milter.txt

1) Start the server¶

. .venv/bin/activate
PYTHONPATH=apps/api uvicorn server.app:app --reload

2) Generate a token (all scopes by default)¶

. .venv/bin/activate
JWT_SECRET=dev-secret python scripts/gen_token.py

3) Call the API with the Python client¶

from nicrypt_stego_client import ClientConfig, TypedNicryptStegoClient

cfg = ClientConfig(
    base_url="http://127.0.0.1:8125/v1",
    token="test-token",
    scopes="keys:manage keys:read provenance:embed provenance:verify models:read models:pull",
)
client = TypedNicryptStegoClient(cfg)

health = client.health()
print(health)
print(health.request_id)

key = client.create_key("legal-team-2026")

stego = client.embed(
    secret="Alice Johnson, 2026-02-12, CC-BY-NC",
    cover_prompt="a short compliance memo about data retention",
)

verified = client.verify(
    stego_text=stego.stego_text,
)
print(verified)
print(verified.request_id)

4) Local library usage (Standalone SDK / MVP stego engine)¶

from nicrypt_stego import protect, verify

secret = "Alice Johnson, 2026-02-12, CC-BY-NC"
topic = "a short compliance memo about data retention"

stego_text = protect(secret, topic, bits_per_token=3, max_new_tokens=200, seed=0)
recovered = verify(stego_text, topic, bits_per_token=3, seed=0)
print(recovered)

Provenance Store (Org-Scoped)¶

Overview - The provenance store is an optional append-only JSONL log for embedded/verified events. - It is useful for audit trails, compliance exports, and incident response. - Events are scoped per org_id when partitioning is enabled.

Environment variables - PROVENANCE_STORE_ENABLED=1 - PROVENANCE_STORE_PATH=/var/log/nicrypt/provenance.jsonl - PROVENANCE_STORE_PARTITION=1

Partitioning rules - If PROVENANCE_STORE_PARTITION=1, logs are written per org_id. - If PROVENANCE_STORE_PATH is a directory, files are named provenance_<org_id>.jsonl. - If PROVENANCE_STORE_PATH is a file, the org_id is appended to the filename.

Sample event

{
  "ts": "2026-02-15T22:21:00.000000+00:00",
  "org_id": "org_a",
  "request_id": "req_abc123",
  "event": "embed",
  "model_name": "sshleifer/tiny-gpt2",
  "model_hash": "mhash_123456",
  "payload_bytes": 42
}

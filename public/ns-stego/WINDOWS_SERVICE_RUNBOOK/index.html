Windows Service Runbook¶

Overview This runbook describes how to run the inbound and outbound SMTP daemons as Windows Services.

Option A: NSSM (Recommended) 1) Download NSSM from https://nssm.cc/download 2) Install the inbound service:

nssm install NicryptInbound "C:\Path\To\python.exe" "C:\Path\To\repo\poc\smtp_inbound_daemon.py" --listen-port 2527
nssm set NicryptInbound AppDirectory "C:\Path\To\repo"
nssm set NicryptInbound AppEnvironmentExtra API_BASE=http://127.0.0.1:8125/v1 API_TOKEN=REPLACE_WITH_TOKEN STAMP_BODY=1
nssm start NicryptInbound

3) Install the outbound service:

nssm install NicryptOutbound "C:\Path\To\python.exe" "C:\Path\To\repo\poc\smtp_relay.py" --listen-port 2525
nssm set NicryptOutbound AppDirectory "C:\Path\To\repo"
nssm set NicryptOutbound AppEnvironmentExtra API_BASE=http://127.0.0.1:8125/v1 API_TOKEN=REPLACE_WITH_TOKEN
nssm start NicryptOutbound

PowerShell Helper Use poc/windows_setup.ps1 for a scripted install. Optional: add NSSM to PATH via -NssmPath.

Makefile Bootstrap (checks NSSM)

$Env:PYTHON_EXE="C:\Path\To\python.exe"
$Env:API_BASE="http://127.0.0.1:8125/v1"
$Env:API_TOKEN="REPLACE_WITH_TOKEN"
$Env:NSSM_PATH="C:\Tools\nssm"
make bootstrap-services

Auto-download NSSM (Makefile) - make bootstrap-services will auto-download NSSM 2.24 to %TEMP% if not found in PATH.

Option B: Task Scheduler (Minimal) Use Task Scheduler to run the daemons on startup with proper environment variables.

Rollback

nssm stop NicryptInbound
nssm remove NicryptInbound confirm
nssm stop NicryptOutbound
nssm remove NicryptOutbound confirm

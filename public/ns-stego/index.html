Nicrypt-Stego Documentation¶

This documentation is organized like a short book so it can be read front-to-back, navigated quickly, and exported/printed cleanly.

Reading Paths¶

  • If you want a working demo fast: Quickstart → Email Provenance → Gateway-Only Manual
  • If you’re deploying for an institution: Production Workflow → Production Readiness → Gateway Integration
  • If you’re building client verifiers: Thunderbird Add-on
  • If you’re doing documents/certificates: Document Workflow → Upload Gateway → Certificate Provenance Sprint
  • If you’re evaluating the business case: Pitch → Monetization

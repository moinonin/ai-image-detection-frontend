Building Distributions¶

This repository produces three separately-installable Python packages: - nicrypt-stego (standalone SDK) - nicrypt-stego-client (typed HTTP client) - nicrypt-stego-api (FastAPI server)

Build All (Recommended)¶

Pick a release directory and build all artifacts (wheels + sdists):

make build-all DIST_DIR=dist/packages/release-0.1.0

Clean + Build¶

To remove dist/ entirely and rebuild fresh (packages + add-ons):

make clean-build

The build output will include: - dist/packages/release-0.1.0/sdk/ - dist/packages/release-0.1.0/client/ - dist/packages/release-0.1.0/api/ - dist/packages/release-0.1.0/README.md (auto-generated install + usage guide)

Build Individually¶

make build-sdk DIST_DIR=dist/packages/release-0.1.0
make build-client DIST_DIR=dist/packages/release-0.1.0
make build-api DIST_DIR=dist/packages/release-0.1.0

Install From Files (Offline)¶

python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip

pip install dist/packages/release-0.1.0/sdk/*.whl
pip install dist/packages/release-0.1.0/client/*.whl
pip install dist/packages/release-0.1.0/api/*.whl

If an institution only needs the offline SDK, distribute and install just sdk/*.whl.

Exchange Transport Agent Runbook¶

Overview This runbook outlines how to deploy and roll back a custom transport agent that calls /v1/provenance/verify_headers and stamps X‑Provenance‑Verified headers.

Prereqs - Exchange On‑Prem with admin access. - Nicrypt‑Stego API reachable from Exchange servers. - JWT token for provenance:verify.

Build 1) Compile the agent assembly (DLL) from poc/exchange_transport_agent.cs. 2) Place the DLL on the Exchange server.

Configure 1) Update poc/exchange_agent/app.config: - ApiBase: API base URL - ApiToken: JWT token

Install (PowerShell)

Install-TransportAgent -Name "NicryptStegoAgent" -TransportAgentFactory "NicryptStegoExchangeAgent.ProvenanceAgentFactory" -AssemblyPath "C:\\Path\\To\\NicryptStegoAgent.dll"
Enable-TransportAgent -Identity "NicryptStegoAgent"
Restart-Service MSExchangeTransport

Validate 1) Send a test email with X‑Provenance‑Ciphertext headers. 2) Check headers on receipt: - X‑Provenance‑Verified - X‑Provenance‑Reason

Rollback

Disable-TransportAgent -Identity "NicryptStegoAgent"
Uninstall-TransportAgent -Identity "NicryptStegoAgent"
Restart-Service MSExchangeTransport

Notes - Always stage in a test environment first. - Use apps/api/server/config/policy.yaml to control enforcement.

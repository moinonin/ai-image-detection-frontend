Deployment Guide¶

Local (Developer Machine) 1. Create a venv and install deps:

python -m venv .venv
. .venv/bin/activate
make setup
  1. Set secrets:
  2. Copy .env.example to .env and set ENC_KEY, ENC_SALT, JWT_SECRET.
  3. Run:
PYTHONPATH=apps/api uvicorn server.app:app --reload

Server (Single Node) 1. Provision a host with Python 3.10+. 2. Install dependencies via make setup. 3. Configure .env (keys + JWT secret). 4. Run with a process manager:

PYTHONPATH=apps/api uvicorn server.app:app --host 0.0.0.0 --port 8000
  1. Configure logs and backups:
  2. logging.json controls structured logs.
  3. Backup apps/api/server/keystore.json and apps/api/server/model_status.json.

Enterprise (On-Prem) Recommended controls - Run behind internal auth gateway or mTLS. - Store keys in a secrets manager (vault/SSM). - Use on‑prem LLMs for privacy. - Enable audit logging and rotate keys regularly.

Checklist - [ ] Secrets stored in vault and rotated - [ ] JWT secret managed by security team - [ ] Logs shipped to SIEM - [ ] API protected behind gateway - [ ] Backup/restore for keystore and model status

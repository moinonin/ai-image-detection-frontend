Email Gateway Flow (Quick Sheet)¶

Diagram (High-Level) Outbound (sign + attachments): Client -> SMTP Relay (inject headers) -> Inbound Verifier (stamp HTML) -> SMTP Provider -> Recipient

ASCII Diagram

[Client] -> [SMTP Relay (inject)] -> [Inbound Verifier (stamp)] -> [SMTP Provider] -> [Mailbox]

make gateway-status

Email vs Certificate Provenance (Quick Comparison) See docs/EMAIL_VS_CERTIFICATE_COMPARISON.md.

Components - Outbound injector: poc/smtp_relay.py (listens on 2525) - Inbound verifier: poc/smtp_inbound_daemon.py (listens on 2527) - Verification API: /v1/provenance/verify_headers - Attachment verification: /v1/provenance/verify_attachment_headers

Quick Start

1) Start API

. .venv/bin/activate
PYTHONPATH=apps/api JWT_SECRET=dev-secret uvicorn server.app:app --reload --port 8125

2) Outbound relay (inject headers)

export API_TOKEN="$(JWT_SECRET=dev-secret python scripts/gen_token.py)"
python poc/smtp_relay.py --listen-port 2525

Configure your SMTP client to use: - Host: localhost - Port: 2525

3) Inbound daemon (verify headers)

export API_TOKEN="$(JWT_SECRET=dev-secret python scripts/gen_token.py)"
python poc/smtp_inbound_daemon.py --listen-port 2527

Configure inbound routing to forward mail to: - Host: localhost - Port: 2527

Reliability flags (SMTP relay / inbound) - SMTP_MAX_ATTEMPTS (default 5) - SMTP_RETRY_BACKOFF (seconds, default 5) - SMTP_API_TIMEOUT (seconds, default 10) - SMTP_INBOUND_QUEUE (JSON queue path) - SMTP_RELAY_QUEUE (JSON queue path)

Headers Injected outbound: - X-Provenance-Ciphertext - X-Provenance-Model - X-Provenance-BPT - X-Provenance-Timestamp - X-Provenance-KeyId - X-Provenance-Attachment (per file)

Stamped inbound: - X-Provenance-Verified - X-Provenance-Reason - X-Provenance-Model-Hash - X-Provenance-Timestamp - X-Provenance-Sender-Domain

IMAP Watcher (PrivateEmail) Use poc/imap_watcher.py to auto-verify headers and move mail to folders:

python poc/imap_watcher.py --imap-user you@domain.com --imap-pass <password>

Verify attachments from .eml

python scripts/verify_attachments.py message.eml --api-token $API_TOKEN

Reliability flags (IMAP watcher) - IMAP_MAX_ATTEMPTS (default 5) - IMAP_RETRY_BACKOFF (seconds, default 5) - IMAP_API_TIMEOUT (seconds, default 10) - IMAP_QUEUE_PATH (JSON queue path)

Environment Template

API_BASE=http://127.0.0.1:8125/v1
API_TOKEN=REPLACE_WITH_RUNTIME_TOKEN

# Relay -> Inbound (local)
SMTP_HOST=127.0.0.1
SMTP_PORT=2527

# Inbound -> Provider
INBOUND_SMTP_HOST=smtp-relay.brevo.com
INBOUND_SMTP_PORT=587
INBOUND_SMTP_USER=your-smtp-login
INBOUND_SMTP_PASS=your-smtp-key

# Gmail PoC
STAMP_BODY=1
